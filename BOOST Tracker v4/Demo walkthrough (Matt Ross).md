# Demo walkthrough: about 5 minutes

Open **BOOST Tracker v4 - DEMO.xlsx**. Every person in it is fictional. Don't open Contact Card on a shared screen in the real file. In the demo it's fine, because the people are made up.

**1. Start Here (15 sec).** "The whole process on one page. Anyone covering a booth can pick it up."

**2. The booth (30 sec).** "People scan the QR at the table and fill in a 90-second form. That's the only data entry they do. Everything they type goes to the Microsoft Forms response file, not to this tracker."

**3. New Sign-Ups (30 sec).** "After an event, this shows everyone who signed up. It's matched to the event automatically by date, and shows initials only. The orange **5** at the top is the number not yet logged. Acton was this week, so those three are still waiting."

**4. People (1 min).** "One row per person: a Participant number and initials. I type the form's Response ID into this orange column and the rest fills in: event, date, type, region, apprentice status, consent. What I add is the part only I can capture: service level, what they need, where they are in the process, and the conversation notes."
*Point at:* the grey cells (not applicable to that contact type), and red **No** consent rows.

**5. Follow-Ups (45 sec).** "This is my call list, soonest first. Red is overdue, amber is due this week. When I've made the call, I enter the date and it drops off."

**6. Event Report (45 sec).** "Pick an event and the report builds itself, then print to PDF. It's what goes to Vito with the expense sheet. It uses initials only, so it's safe to email."

**7. Dashboard (45 sec).** "Totals across all events, how we're tracking against the performance commitments, and which events are producing sign-ups and follow-ups. Self-identification comes straight from the form as totals only. It's never stored against a person."

**8. Contact Card (15 sec).** "When I actually need to call someone, I type their number here and the contact details appear. It's the only place they show, and it doesn't print."

## If asked

* **Where does personal information live?** In the Microsoft Forms response file in the LLSC OneDrive. The tracker holds a number, initials and work notes.
* **What if someone doesn't use the QR?** Add them as a walk-up: date, initials, type. The event fills from the date.
* **Two events on the same day?** The Event ID turns amber to flag it. Even better, add a pre-filled event question to the form so each QR carries its event.
* **Can someone else use it?** Yes. Start Here covers it, and the dropdowns keep everyone's entries consistent.
* **Is it hard to keep up?** About two minutes per event to log sign-ups. The rest is the notes, which you'd write anyway.
